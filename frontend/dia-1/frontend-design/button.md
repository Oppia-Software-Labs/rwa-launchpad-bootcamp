# Button

## Variantes

- `primary`: acción principal, azul o gradiente.
- `secondary`: superficie elevada con borde.
- `ghost`: transparente, para acciones de bajo énfasis.
- `danger`: únicamente para acciones destructivas.

## Estados

`default`, `hover`, `pressed`, `focus`, `disabled`, `loading`.

## Reglas

- Texto corto y orientado a una acción.
- Peso 600.
- Alto consistente y área táctil mínima de 44 px en móvil.
- El estado focus debe ser visible y no depender solo del color.
